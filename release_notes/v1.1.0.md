小黑工具箱現在共有 7 個工具，新增圖片批次處理、PDF 工具，並將 QR Code 擴充為產生與圖片辨識。

## 新功能

- **圖片批次處理**：保持比例縮圖、壓縮與 PNG / JPG / WebP 互轉；調整品質、透明圖轉 JPG 的背景色及拍攝資訊保留。比較前後大小，單張下載或打包 ZIP；重複檔名自動加序號。
- **PDF 工具**：縮圖預覽、合併、抽頁、拖曳排序、旋轉與逐頁拆分 ZIP。支援輸入密碼開啟受保護文件，同名表單欄位的值可保留。
- **QR 圖片辨識**：拖入圖片或 Ctrl+V 貼上截圖，支援同圖多個 QR、複製內容與手動開啟網址。產生的 QR 下載圖保留掃描留白，修正中文內容的隱藏 UTF-8 標記。
- **工具切換**：首頁新增入口，窄視窗導覽可用選單切換工具。

## 修正與更新

- 圖片上傳格式、容量、解析度和損壞檔案驗證。
- OCR 語言組合、模型切換與打包後的離線模型路徑修正，包含五種支援語言的模型。
- 改善去背預覽、PNG 轉 ICO、文字轉檔、QR 顏色／內容變更及檔案下載流程。
- 更新下載啟用 TLS 憑證驗證，更新包加入安全路徑、版本與差量基準驗證；打包保留舊版本供回復。

## 下載

- 新使用者下載 **littleblacktoolbox_v1.1.0.zip**（約 1.48 GB），解壓後雙擊 `小黑工具箱.exe`。
- **littleblacktoolbox_v1.1.0_patch.zip**（約 136 MB）以已公開的 **v1.0.1** 為更新基準，供程式內建更新流程使用；其他版本請下載完整包。
- SHA-256 校驗碼見 **SHA256SUMS.txt**。

圖片批次最多 50 張、合計 50 MB；PDF 最多 20 份文件、合計 50 MB、500 頁。加密 PDF 的新輸出不保留開啟密碼；編輯會使原數位簽章失效。檔案均在本機處理，七項工具可離線使用；版本檢查及更新需要網路。

## 驗證

21 項 unittest、36 段 JavaScript 語法檢查通過；完整 EXE 與公開 v1.0.1 套用差量包後的圖片、PDF、QR、OCR 與 BiRefNet 通過實際測試。完整／差量包通過 CRC、SHA-256、版本、前端檔案與公開更新基準檢查。
