## 完成項目

### 1. 徹底修復：瀏覽器重複開啟 BUG

- **問題回顧：** PyInstaller 打包後，rembg/onnxruntime 內部的子進程會重新載入 app.py，觸發 `open_browser()`，導致瘋狂開新分頁
- **修法：** 使用 `os.environ` 環境變數旗標（`__TOOLBOX_RUNNING__`）
  - 環境變數會被子進程繼承，所以子進程看到旗標就不會再開瀏覽器
  - 比全域變數（跨進程無效）和檔案鎖（太重）都更優雅
- **狀態：** ✅ 開發模式測試通過（待下次打包驗證 exe）

### 2. 修復：rembg 預載入競態條件

- 使用 `threading.Event()` 機制（`rembg_loading`），API 收到請求時會先 `wait()` 等模型載入完成
- 避免模型還沒載好就收到去背請求而報錯

### 3. AI 去背模型升級：U2-Net → BiRefNet

- **原因：** 小黑測試後覺得預設 U2-Net 去背品質不夠好
- **改動：**
  - `new_session("birefnet-general")` 改用 BiRefNet 模型（最新一代，邊緣最細膩）
  - 加上 `post_process_mask=True` 進一步優化遮罩邊緣
- **效果：** 下載的去背結果品質明顯提升，邊緣乾淨

### 4. 修復：去背預覽看不出效果（重大 UI BUG）

- **問題：** 右側對比滑桿中，去背後的透明 PNG 直接疊在原圖上方 → 透明的地方透過去看到原圖 → 使用者以為完全沒去背
- **實際上：** 下載的檔案是完美去背的，只是預覽顯示方式有問題
- **修法：**
  - before（原圖）和 after（去背結果）各用 `clip-path` 佔滑桿的一邊，不再重疊
  - 左邊 = 去背結果（透明處顯示棋盤格）
  - 右邊 = 原圖
  - 拖曳滑桿即可清楚看到差異
- **同步更新：**
  - 底部徽章文字 `U2-Net 深度學習` → `BiRefNet 深度學習`
  - 滑桿標籤改為 `← 去背結果（棋盤格 = 透明）` / `原圖 →`

## 下次可以新增的實用離線小工具推薦

### 🥇 圖片批次壓縮器

- **功能：** 拖入多張圖片 → 調整品質/尺寸 → 一鍵批次壓縮 → 打包下載
- **實用場景：** 上傳作業、寄 Email 附件太大、網站素材優化
- **技術：** Python Pillow 後端處理，可設定目標大小（例如每張壓到 500KB 以下）
- **難度：** ⭐⭐ 簡單，Pillow 已經裝了

### 🥈 圖片格式轉換器

- **功能：** PNG ↔ JPG ↔ WebP ↔ BMP ↔ GIF 互轉，支援批次
- **實用場景：** 網站要 WebP、某些系統只吃 BMP、社群平台限制格式
- **技術：** Python Pillow，跟壓縮器可以合併成一個「圖片工坊」
- **難度：** ⭐⭐ 簡單

### 🥉 色碼轉換器 + 調色盤

- **功能：** HEX ↔ RGB ↔ HSL 即時互轉、顏色預覽、配色建議、螢幕取色
- **實用場景：** 寫 CSS、做設計、挑 UI 顏色
- **技術：** 純前端 JavaScript，不需後端
- **難度：** ⭐ 最簡單

### 密碼產生器

- **功能：** 設定長度、包含大小寫/數字/符號 → 一鍵生成高強度密碼 → 複製
- **實用場景：** 註冊新帳號、定期更換密碼
- **技術：** 純前端 JavaScript
- **難度：** ⭐ 最簡單

### JSON / XML 格式化瀏覽器

- **功能：** 貼入雜亂的 JSON 或 XML → 自動美化排版 + 樹狀結構瀏覽 → 可搜尋、折疊、複製路徑
- **實用場景：** API 開發 debug、看設定檔、分析資料
- **技術：** 純前端 JavaScript
- **難度：** ⭐⭐ 中等

### 影片轉 GIF

- **功能：** 上傳短影片 → 選擇時間範圍 → 調整大小和幀率 → 轉成 GIF
- **實用場景：** 做梗圖、聊天動圖、教學截圖
- **技術：** Python moviepy 或 ffmpeg，需額外安裝
- **難度：** ⭐⭐⭐ 較複雜，打包也比較麻煩

### Markdown 即時預覽編輯器

- **功能：** 左邊打 Markdown、右邊即時預覽渲染結果，可匯出 HTML/PDF
- **實用場景：** 寫筆記、寫文件、寫 README
- **技術：** 純前端（marked.js 已經下載了），不需後端
- **難度：** ⭐⭐ 中等
