# 2026-10-01 小黑工具箱 v1.1.0

使用者授權一次完成圖片批次處理、PDF 工具與 QR 圖片辨識，完成後推送 GitHub。

## 功能

- 工具箱由 5 項擴充為 7 項，首頁及導覽增加圖片批次處理與 PDF 工具，QR 生成頁整合圖片辨識。
- 圖片：50 張／50 MB 批次，PNG／JPG／WebP 轉換，按比例縮圖、不放大小圖，透明圖轉 JPG 底色、品質、EXIF／ICC 選擇，EXIF 方向校正，大小比較與 ZIP 重名處理。
- PDF：20 份／50 MB／500 頁，PDF.js 本機縮圖預覽，選頁／範圍與反向頁序、拖曳與箭頭排序、旋轉、合併或逐頁 ZIP，支援 AES 密碼來源，合併同名表單欄位不丟值。
- QR：拖圖、貼上截圖、同圖多碼、複製與手動開啟網址；中文 qrcode.js 往返測試修正 UTF-8 BOM，產生器下載／複製保留四個模組的留白。
- 整合上一輪未提交的上傳驗證、OCR 五語言打包模型、既有工具／預覽／下载、TLS 與更新 ZIP 驗證修正。

## 驗證

- 21 項 unittest 與 36 段 JavaScript 語法檢查通過。
- 內建瀏覽器確認兩張同名圖片轉 WebP、PDF 抽頁與旋轉／密碼開啟、QR 圖片辨識與複製；保存實際頁面截圖於本機 build/verification。
- 完整 EXE HTTP 實測：版本、全部頁面、透明 WebP、中文 QR、加密 PDF 合併／拆分、繁中 OCR、BiRefNet，均通過。
- 下載 GitHub 公開 v1.0.1 完整 ZIP，比較本機 manifest：2906 項、0 差異。差量以公開版本作為基準。
- 原始 v1.0.1 解壓後覆蓋 v1.1.0 差量 ZIP，再執行相同 EXE 測試，均通過。
- 最終完整 ZIP 1,483,863,803 bytes，SHA-256 `35871d10d295cf04d57c6c45a2fb8078b4d76014a2d748037891f5d32a0b9460`。
- 最終差量 ZIP 136,288,987 bytes，SHA-256 `2308d7af12ee77622ae09d3c078e51a16d86718b610491a505b603f92e5fb20f`。
- 3389 項發行檔案的 CRC／SHA-256、版本、差量基準及打包前端與工作目錄一致性通過。

## 實際限制

- 圖片目前僅支援靜態 PNG／JPEG／WebP；重新編碼不保證檔案更小。
- 新輸出 PDF 不保留來源開啟密碼，編輯會使原數位簽章失效。
- Chrome 自動上傳測試因 ChatGPT extension 未允許 file URLs 而不可用；本次上傳與操作以內建瀏覽器驗證。窄視窗自動化後續遇到瀏覽器控制逾時，未宣稱完成全部窄視窗互動驗證。

發行說明與校驗碼隨 v1.1.0 Release 提供；建置、測試環境和大型 ZIP 不提交 Git。
