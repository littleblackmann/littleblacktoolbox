# 2026-10-01 小黑工具箱 v1.1.0

使用者授權一次完成圖片批次處理、PDF 工具與 QR 圖片辨識，完成後推送 GitHub。

## 功能

- 工具箱由 5 項擴充為 7 項，首頁及導覽增加圖片批次處理與 PDF 工具，QR 生成頁整合圖片辨識。
- 圖片：50 張／50 MB 批次，PNG／JPG／WebP 轉換，按比例縮圖、不放大小圖，透明圖轉 JPG 底色、品質、EXIF／ICC 選擇，EXIF 方向校正，大小比較與 ZIP 重名處理。
- PDF：20 份／50 MB／500 頁，PDF.js 本機縮圖預覽，選頁／範圍與反向頁序、拖曳與箭頭排序、旋轉、合併或逐頁 ZIP，支援 AES 密碼來源，合併同名表單欄位不丟值。
- QR：拖圖、貼上截圖、同圖多碼、複製與手動開啟網址；中文 qrcode.js 往返測試修正 UTF-8 BOM，產生器下載／複製保留四個模組的留白。
- 整合上一輪未提交的上傳驗證、OCR 五語言打包模型、既有工具／預覽／下载、TLS 與更新 ZIP 驗證修正。

## 驗證

- 21 項 unittest 與 36 段 JavaScript 語法檢查通過。
- 內建瀏覽器確認兩張同名圖片轉 WebP、PDF 抽頁與旋轉／密碼開啟、QR 圖片辨識與複製；保存實際頁面截圖於本機 build/verification。
- 完整 EXE HTTP 實測：版本、全部頁面、透明 WebP、中文 QR、加密 PDF 合併／拆分、繁中 OCR、BiRefNet，均通過。
- 下載 GitHub 公開 v1.0.1 完整 ZIP，比較本機 manifest：2906 項、0 差異。差量以公開版本作為基準。
- 原始 v1.0.1 解壓後覆蓋 v1.1.0 差量 ZIP，再執行相同 EXE 測試，均通過。
- 最終完整 ZIP 1,483,863,803 bytes，SHA-256 `35871d10d295cf04d57c6c45a2fb8078b4d76014a2d748037891f5d32a0b9460`。
- 最終差量 ZIP 136,288,987 bytes，SHA-256 `2308d7af12ee77622ae09d3c078e51a16d86718b610491a505b603f92e5fb20f`。
- 3389 項發行檔案的 CRC／SHA-256、版本、差量基準及打包前端與工作目錄一致性通過。

## 實際限制

- 圖片目前僅支援靜態 PNG／JPEG／WebP；重新編碼不保證檔案更小。
- 新輸出 PDF 不保留來源開啟密碼，編輯會使原數位簽章失效。
- Chrome 自動上傳測試因 ChatGPT extension 未允許 file URLs 而不可用；本次上傳與操作以內建瀏覽器驗證。窄視窗自動化後續遇到瀏覽器控制逾時，未宣稱完成全部窄視窗互動驗證。

發行說明與校驗碼隨 v1.1.0 Release 提供；建置、測試環境和大型 ZIP 不提交 Git。

# 2026-10-01 小黑工具箱 v1.2.0

使用者授權新增實用工具、調整外觀並完成 GitHub 推送；本輪延續既有發行授權。

## 功能

- 工具由 7 項增加至 9 項，以共用工具目錄產生首頁及導覽。
- 首頁加入用途搜尋、分類、收藏、最近使用、Ctrl+K 全域搜尋，縮小留白並提高文字對比；窄視窗仍可切換全部工具。
- 圖片標註：原解析度 Canvas、箭頭／框線／畫筆／文字／馬賽克／實色遮蔽、裁切、100 步復原重做、PNG／JPG／WebP 匯出及複製 PNG。
- 批次檔案改名：本機資料夾一層、自然排序、流水號／取代／前後綴／日期、保留副檔名、預覽後執行；檢查重名、來源變更、Windows 名稱及硬連結，兩階段改名支援交換名稱與大小寫改名。
- 改名每一步寫入持久復原紀錄，支援跨程式重開的復原、失敗回滾及中斷操作恢復；API 限本機並要求每次執行的隨機 token。
- 記住各工具的設定與收藏，不儲存圖片／文件內容或改名資料夾路徑。
- 圖片批次支援去背 → 縮圖 → WebP、自訂最多 10 組設定、進度、取消、單張重試與失敗項目重試；斷線錯誤改為繁中可操作提示。

## 驗證

- 31 項 unittest、55 段 JavaScript 語法檢查通過。
- 真實暫存檔測試：自然排序、改名／重開後復原、重名防護、來源變更、交換／大小寫、失敗回滾、復原失敗可重試、階段中斷恢復與本機 token／Origin 防護。
- Chrome 實際操作：首頁搜尋／收藏／最近使用、全域搜尋、375px 首頁及標註頁無橫向溢出；Ctrl+V 貼上 900×500 圖片並加箭頭、文字、實色遮蔽，裁切後復原／重做，複製匯出 750×400 PNG，核對像素、尺寸與無 EXIF。
- Chrome 實際批次改名：截圖2／截圖10 自然排序，改為 001／002，重新整理後復原，檔案系統名稱核對正確。
- Chrome 實際圖片流程：自訂 450px 設定保存後重新整理可還原，輸出 450×250 WebP；完整 EXE 去背 → WebP 通過。停止測試 EXE 造成兩張失敗後，單張重試成功，再重試剩餘失敗項目，保留已成功結果。
- 完整 EXE 與公開 v1.1.0 覆蓋 v1.2.0 差量包的 EXE，均實測版本、10 個頁面、透明 WebP、中文 QR、加密 PDF 合併／拆分、真實改名／復原、繁中 OCR 及 BiRefNet，全部通過。
- 本機 v1.1.0 基準完整包與 GitHub 公開資產 SHA-256 相符，3389 檔案與基準 manifest 無差異。
- 最後三份前端斷線提示修正重新封裝，完整包／差量包與來源核對，再覆蓋升級測試目錄，3397 檔案吻合；升級 EXE 基本測試再次通過，後端及 AI 二進位未變。

- 最終差量 ZIP：57,424,491 bytes，SHA-256 `723f6c7afd778f9d81ce18a3ba502cbbc8b48b89a7de352346dc81ab8c7797a7`。
- 發行包 3397 項檔案 CRC／SHA-256、版本、差量基準及前端來源一致性通過。

## 實際限制

- 原生 Windows 選資料夾對話框未做 UI 自動化；輸入資料夾路徑的完整改名／復原流程已實測。
- Chrome 自動選檔需要 extension 的 file URL 權限，本次未更改權限，以剪貼簿 PNG 實測圖片流程。內建瀏覽器可讀畫面與截圖，但本次點擊未送出頁面事件，互動驗證改用 Chrome。
- 標註最多 50 MB／3000 萬像素／300 筆；改名最多 1000 個本機檔案，原名被占用或檔案被其他程式更動時停止復原。
- 實測資料與改名歷史使用 build/verification 專用目錄，未使用人類的原始檔案。
